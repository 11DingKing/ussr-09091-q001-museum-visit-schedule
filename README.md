# 纪念馆分时参观调度

本项目面向吉林大学朝阳校区纪念馆的现场接待工作。系统边界包括预约入口、展厅资源、现场状态和运营查询，后续功能应围绕这些边界保持清晰的数据流。

## 目录约定

- `src/visit_schedule/domain.py`：预约领域对象和状态值。
- `src/visit_schedule/`：应用服务与持久化适配器的放置位置。
- `tests/`：可重复执行的业务测试。

## 运行

项目仅使用 Python 标准库，执行 `python -m unittest discover -s tests` 可运行现有检查。运行参数和数据库路径通过环境变量或应用入口传入，不把本地密钥提交到仓库。
